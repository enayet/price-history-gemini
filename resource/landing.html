Technical Questions Answered

Does this work with WooCommerce HPOS (High Performance Order Storage)?
Yes, fully compatible. The plugin declares HPOS compatibility and uses WooCommerce's recommended practices. Future-proofed for WooCommerce's direction.
Will this slow down my store?
No. Price tracking only happens when you update products (not on every page load). The compliance message uses cached data. Charts load asynchronously and only when needed.
How accurate is the legal compliance?
Built specifically for EU Omnibus Directive requirements. The "lowest price in X days" calculation follows the exact legal requirements. However, always verify with your legal team for your specific jurisdiction.
Does it work with variable products properly?
Yes, this was a key design requirement. Each variation (size, color, etc.) has separate price tracking. When customers select a variation, they see that variation's price history - not generic product data.
What happens to data if I deactivate the plugin?
Price history data remains in your database. If you reactivate, all history is preserved. The plugin includes export functionality if you need to backup your compliance records.
Can I customize where the compliance message appears?
Yes, through WooCommerce hooks. The default position is below the price, but developers can move it using standard WordPress filters. Full documentation included.
