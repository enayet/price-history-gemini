A WooCommerce addon that tracks product price history and displays the lowest price in the last 30 days on product pages during a sale.

== Description ==

This plugin ensures your WooCommerce store complies with consumer protection laws like the EU’s Omnibus Directive by tracking product price history. It automatically records price changes and displays the lowest price in the last 30 days on the product page when an item is on sale.

It also includes an optional, visually appealing chart of the price history to build customer trust.

== Installation ==

1. Create a zip file from the `wc-price-history-compliance` directory.
2. Go to your WordPress admin area and navigate to 'Plugins > Add New'.
3. Click 'Upload Plugin', choose the zip file you created, and click 'Install Now'.
4. Activate the plugin through the 'Plugins' menu in WordPress.
5. Configure the settings under 'WooCommerce > Settings > Price History'.

== Features ==

* **Automated Price Tracking:** Automatically records every price change for simple and variable products.
* **30-Day Lowest Price Display:** Shows the lowest price in the last 30 days on sale products, as required by law.
* **Price History Chart:** Optionally displays a simple line chart of past prices for transparency.
* **Customizable Messaging:** Adjust the compliance message text from the settings.
* **Admin Reports:** View a log of all recorded price changes in the WordPress admin area.
